# Pokédex

Aplicação web que mostra os 151 Pokémon originais, com pesquisa por nome ou número, filtros por tipo e janela de detalhes. Qualquer outro Pokémon pode ser procurado diretamente na PokéAPI.

**Ver online:** https://o-teu-utilizador.github.io/pokedex/

## Tecnologias
- HTML, CSS e JavaScript
- [PokéAPI](https://pokeapi.co/)

## O que aprendi
- Pedidos a APIs com `fetch` e `async/await`
- `Promise.all` para pedidos em paralelo
- Manipulação do DOM, filtros e tratamento de erros
